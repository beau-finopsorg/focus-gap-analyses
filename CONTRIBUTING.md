# Contributing

Thanks for helping make these reports more accurate. These are unofficial community reports. See [DISCLAIMER.md](DISCLAIMER.md).

## Propose a correction

1. Open a [vendor correction issue](https://github.com/beau-finopsorg/focus-gap-analyses/issues/new?template=vendor-correction.yml), or send a pull request that edits the report.
2. Name the report and its "Analysis run" date.
3. Say what is wrong and link public evidence.
4. Propose the corrected text.

## Propose a new analysis

Open a [new data generator issue](https://github.com/beau-finopsorg/focus-gap-analyses/issues/new?template=new-data-generator.yml) first. A pull request with a draft report is welcome after that.

## Rules

- One vendor per pull request.
- Cite public sources: documentation, changelogs, or sample exports. Private or confidential material is not accepted.
- Use plain, factual language. No marketing language.
- Use only the rating scale: Aligned, Partially aligned, Not yet aligned (per public docs).
- Do not add logos or official-looking footers.
- If you work for the vendor, say so in your issue or pull request.
- Keep the "Analysis run" date accurate. Update it when you update the reading.

## Review

Maintainers may edit for tone and for the rating scale. A correction with solid public evidence will be accepted even if it changes a rating.
