# Readiness reports

This folder holds the full red-amber-green (RAG) readiness view that goes with the written analyses.

- [FOCUS-Readiness-Dashboard.html](FOCUS-Readiness-Dashboard.html) — five-dimension scorecard for each provider, plus official Foundation status where it exists.
- [gap-analyses-by-company.html](gap-analyses-by-company.html) — an index of every written analysis.

These pages are unofficial community work. They are not an official FOCUS, FinOps Foundation, or Linux Foundation publication. See [../DISCLAIMER.md](../DISCLAIMER.md).

## How to read the ratings

Written analyses and the overall band on the dashboard use this scale:

- **Aligned:** public documentation indicates the product's cost and usage data matches the relevant version of the specification for the columns and behaviors in scope of the analysis.
- **Partially aligned:** public documentation shows some of the required shape or columns, with documented gaps.
- **Not yet aligned (per public docs):** public documentation does not show a specification-shaped export, or the gaps are substantial.

The dashboard also keeps two official Foundation statuses, which are not ratings from this repo:

- **FinOps Certified FOCUS Conformant** (shown with a specification version, for example v1.2): certified by the FinOps Foundation.
- **Supported** (with a specification version): the vendor has given the Foundation an export and is listed on the get-started page.

The five dimension scores (Cost, Granularity, Allocation, Coverage, and specification shape) stay on the original Strong / Partial / Gap rubric. Only the overall community band was mapped to the three-level scale:

| Band used in the private drafts | Published overall rating |
| --- | --- |
| Conformant | Aligned |
| Near-ready | Partially aligned |
| Advanced | Partially aligned |
| Structured | Partially aligned |
| Emerging | Not yet aligned (per public docs) |
| Nascent | Not yet aligned (per public docs) |

Ratings are a reading of public documentation on the date in each analysis. They may be incomplete or out of date, and they are not a certification result.
